**작성 2026-09-01, 학습 진행 중·결과 확인 전.** v1(PREREGISTRATION.md)의 세 게이트가 모두
"격차 < 시드폭"으로 판정 불가였고, 그 원인을 규명해 설계를 바꾼 뒤의 재판정 문서다.

## 2. v2 의 개입 (v1 대비 바뀐 것만)

1. **예측기가 정책 안에 있다** — 입력 `[z_e(o), z_p, ẑ_e(o+k)]`, k=100. 배포 시에도 살아 있고
   행동손실이 직접 통과하므로 씻겨나갈 수 없다.
2. **보조손실이 증류 내내 걸린다** — 초기화가 아니라 지속 개입.
3. **학습 중 관측 노후화** `d ~ U[0,25]` 스텝, 에피소드 내 상수 — 예측기에 실제 할 일을 준다.
4. 명령 범위 0.3~0.6 → **0.6~1.5 m/s**, 회전 0 → **±0.6 rad/s**.

## 3. 비교 조건 — 구조 동일, 목적함수만 다름

세 조건 모두 `predictor_in_policy=True`. **배포 경로 파라미터 498,427 로 동일**(검증 완료).
유일한 변수는 그 예측기 MLP 를 무엇이 학습시키느냐다.

| 조건 | 보조손실 | 감독 신호 | 실기 학습 |
|---|---|---|---|
| `jepa` | λ_jepa=1, ẑ(t+100) vs EMA 타깃 | 자기지도 | ✅ |
| `recon` | λ_recon=1, z_e → GT 높이맵 | **특권**(시뮬 raycaster) | ❌ |
| `none` | 없음 (행동손실만) | — | ✅ |

n=5 (seed 1~5). teacher·환경·하이퍼파라미터 전부 동일. eval_seed=42 고정.

## 4. 판정 기준 — 결과 확인 전 고정

**공통 규칙(v1 에서 도출):** 조건 간 평균 격차가 **최대 조건내 시드폭을 초과**할 때만 신호로
인정한다. v1 에서 마진을 절대값(2.0pp)으로 미리 박았다가 실제 시드폭(2.6~7.8pp)이 그보다
커져 검정력 논거가 무너졌다. 시드폭 기준은 자기교정된다.

### 게이트 1 — 무결손 대등성 (주 주장)
- 지표: 결손 레벨 0 성공률
- 성공: `jepa` 가 `recon` 대비 시드폭 이내이거나 우위
- **`none` 도 함께 보고한다.** v1 에서 scratch 가 1위였다 — 보조손실이 무결손 성능을 해치지
  않는지가 전제 조건이다.

### 게이트 2 — 공간 결손 (occlusion)
- **사전 예측: `recon` ≥ `jepa`.** v1 에서 전 시드 무겹침으로 recon 우위였고, v2 에서도
  recon 의 보조손실은 여전히 공간 복원이다. 뒤집힐 이유가 없다.
- 이 게이트에서 지는 것을 결과에서 빼지 않는다.

### 게이트 3 — 시간 결손 ★핵심
> `jepa` 는 `ẑ_e(t+100)` 를 정책 입력으로 쓰고, 노후화된 관측으로 학습했다. 따라서
> **관측이 시간적으로 끊기는 고장**에서 `recon`·`none` 대비 우위가 있어야 한다.

- **사전 예측: `jepa` > `none`, 그리고 `jepa` > `recon`**
- 지표: 성공률-레벨 곡선의 AULC (v1 과 동일. 최대강도 성공률은 **탐색적**으로만 병기)
- **학습 범위 밖에서 판정한다.** 세 조건 모두 학습 중 `d ≤ 25` 를 봤으므로 그 안에서는
  전부 적응했을 것이다. 일반화를 보려면 더 밀어야 한다:
  - `latency` — eval 상한을 **50 스텝**으로 올린다(현재 10). level 1.0 = 학습 최대의 2배
  - `freeze` — level 1.0 = 무한 노후화. 이미 학습 범위 밖
  - `lowfps` — 현행 유지
- **예측이 틀렸을 경우: 그대로 보고한다.** 지표를 바꾸지 않는다.

### 게이트 4 — 예측기가 실제로 쓰이는가 (신규, 기전 검증)
강인성은 간접 증거다. 정책이 `ẑ` 를 **실제로 쓰는지**를 직접 잰다.
- 방법: eval 시 정책 입력의 `ẑ` 블록만 0 으로 치환(다른 것 전부 동일) → 성공률 낙폭
- **사전 예측: 낙폭(`jepa`) > 낙폭(`none`)**
- 의미: `jepa` 가 크면 자기지도 예측이 정책에 실제로 기여하는 것. 셋 다 0 에 가까우면
  예측기는 장식이고, v2 개입도 실패한 것이다 — **그 경우 그렇게 보고한다.**

## 5. 보고 규칙

1. 네 게이트를 **모두** 보고한다. 진 게이트를 빼지 않는다.
2. v1 결과와 **직접 비교하지 않는다** — 명령 범위(0.3~0.6 → 0.6~1.5)가 달라 환경이 다르다.
   v1 은 "초기화만으로는 부족하다"의 근거로 인용하고, 성능 수치는 비교하지 않는다.
3. 사정거리: 본 연구의 `jepa` 는 I-JEPA(공간 마스킹)가 아니라 **시간 예측 변형**이다.
   결론은 "예측 일반"이 아니라 **"시간 예측"** 으로 한정한다.
4. 알려진 한계: `recon`(관측공간·현재)과 `jepa`(표현공간·미래)는 2×2 의 대각선이라 공간/시간
   두 축이 동시에 다르다. Head C(자기지도 관측공간 재구성)는 **future work 로 명시**한다.
5. **9/3 조기 판정은 n=3 이다.** 확정 판정은 n=5 로만 한다. 조기 판정은 실험 계속/수정
   결정에만 쓰고, 논문에는 n=5 만 싣는다.
