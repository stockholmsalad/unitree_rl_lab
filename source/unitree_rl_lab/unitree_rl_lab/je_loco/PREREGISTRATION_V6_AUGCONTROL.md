# 사전 등록 v6 — 결손 증강의 귀속 대조군

**작성 2026-09-10, V6 학습 시작 전·결과 확인 전.**

## 1. 무엇을 묻는가

V5(`jepa` + 학습 중 결손 증강)에서 공간 차폐 강인성이 크게 올랐다.

```
v2 jepa (증강 없음)   occlusion AULC 27.13
V5 jepa (증강 있음)   occlusion AULC 51.58 (seed 1)
```

**이 향상이 표현 목적함수 때문인가, 증강 때문인가**를 이 실험이 가른다. V5 는 세 가지를
동시에 바꿔(차폐 증강·노후화 확대·지평 정합) 귀속이 불가능했다.

## 2. 개입

`recon` 조건에 **V5 와 동일한 증강**을 건다.

```
repr_head = recon,  lambda_recon = 1.0,  lambda_jepa = 0.0
train_occlusion_max = 0.5      ← V5 와 동일
train_staleness_max = 50       ← V5 와 동일
```

그 외 전부 v2·V5 와 같다. `predictor_in_policy` 도 유지해 배포 파라미터 수를 맞춘다.
시드 1~3 (n=3).

## 3. 판정 기준 — 결과 확인 전 고정

비교 대상은 네 지점이다.

| | 무결손 | occlusion AULC |
|---|---|---|
| v2 `jepa` (증강 없음) | 85.76 | 27.13 |
| v2 `recon` (증강 없음) | 88.20 | 38.75 |
| V5 `jepa` (증강 있음) | 측정값 | 측정값 |
| **V6 `recon` (증강 있음)** | **?** | **?** |

**주 판정 — 증강 효과가 목적함수에 의존하는가**

- **결과 A.** V6 의 AULC 향상폭(V6 − v2 recon)이 V5 의 향상폭(V5 − v2 jepa)과
  시드폭 안에서 같다 → **증강이 원인이고 목적함수는 무관하다.**
- **결과 B.** V6 의 향상폭이 V5 보다 시드폭을 넘어 작다 → **증강 효과가 예측 표현에서
  더 크다.** 목적함수가 증강과 상호작용한다는 뜻이며, 이 경우 예측 표현 쪽에 유리한 결과다.
- **결과 C.** V6 가 V5 를 넘어선다 → 재구성 + 증강이 최선이다. 그대로 보고한다.

**부 판정 — 무결손 성능**

증강이 무결손 성능을 해쳤는지 본다. V5 는 오히려 올랐다(85.76 → 93.4).
V6 가 v2 recon(88.20) 대비 시드폭 넘게 떨어지면 명시한다.

## 4. 보고 규칙

1. 세 결과(A/B/C) 중 무엇이 나오든 그대로 보고한다. **B 가 나오길 바라는 실험이지만
   A 가 나와도 논문은 성립한다** — 그 경우 결론이 "표현 목적함수는 강인성을 좌우하지
   않으며 결손 노출이 좌우한다"가 된다.
2. V5 는 세 변수를 동시에 바꿨으므로, V6 와의 비교도 **증강 유무 한 축으로만** 해석한다.
   지평·노후화 차이는 V5 와 V6 가 동일하게 맞췄으므로 상쇄된다.
3. n=3 이며 V5 는 n=2 다. 시드 수가 다름을 명시한다.
