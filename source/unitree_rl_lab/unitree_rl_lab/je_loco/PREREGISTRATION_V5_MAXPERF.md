# 탐색적 실험 v5 — jepa 최대 성능 설정

**작성 2026-09-08 17:15, 학습 진행 중·결과 확인 전.**

## 0. 지위

**사전 등록된 확정 실험이 아니다.** v2 결과 동결일(9/7) 이후에, v2 의 결과를 보고 설계했다.
논문에서 **탐색적 실험으로 명시**하고 v2 의 네 게이트 판정과 섞지 않는다.
그럼에도 판정 기준은 결과를 보기 전에 이 문서로 고정한다.

## 1. 목적 — 통제 비교가 아니다

v1·v2 는 변수 하나만 남기는 통제 비교였다. v5 는 목적이 다르다:

> **자기지도 예측 표현으로 학습한 정책의 보행 성능을 최대화한다.**

따라서 **여러 설정을 동시에 바꾼다.** 그 대가로 **어느 변경이 어떤 효과를 냈는지 귀속할 수
없다.** 이것은 설계상 받아들인 한계이며 보고할 때 명시한다.

## 2. 개입 — v2 대비 셋

| 설정 | v2 | v5 | 근거 |
|---|---|---|---|
| 학습 중 공간 차폐 | 없음 | **level ~ U[0, 0.5]** | v2 jepa 가 occlusion 0.4 에서 **5/5 시드 붕괴**(AULC 27.13, recon 38.75). 학습에서 겪지 않은 고장이었다 |
| 학습 중 노후화 | d ≤ 25 | **d ≤ 50** | d≤25 는 낡은 관측이 현재와 거의 같아 예측이 필요 없다. skill 이 짧은 지평에서 낮은 것이 그 방증 |
| 예측 지평 k | 100 | **25** | E[d] = 25 와 일치. v2 는 2.0 s 앞을 예측하는데 노후화는 0.5 s 였다 |

조건은 `jepa` 하나, 시드 1~3 (n=3). 그 외 전부 v2 와 동일.

## 3. 판정 기준 — 결과 확인 전 고정

평가는 어려운 지형에서만 수행한다(v2 와 동일 프로토콜, eval_seed 42).

### 주 판정 — 공간 차폐 강인성

- 지표: occlusion AULC
- **성공: v2 jepa(27.13) 를 두 실험의 최대 시드폭을 넘어 상회**
- **강한 성공: v2 recon(38.75) 도 상회**
- 보조 관측: 레벨 0.4 에서 생존한 시드 수 (v2 jepa 는 0/5)

### 부 판정 — 무결손 성능을 대가로 지불하지 않았는가

- 지표: 결손 레벨 0 성공률
- **조건: v2 jepa(85.76%) 대비 시드폭 이내를 유지해야 한다**
- 이 조건이 깨지면 차폐 강인성이 올라도 **"강인성을 무결손 성능과 맞바꿨다"**로 보고한다

### 부 판정 — 시간 결손과 예측기 사용

- freeze · latency · lowfps AULC, 그리고 ẑ 절제 낙폭
- v2 대비 변화만 기술한다. 주 판정이 아니다

## 4. 보고 규칙

1. **세 변수를 동시에 바꿨으므로 개별 귀속을 하지 않는다.** "차폐 증강 때문에 좋아졌다"고
   쓰지 않는다. 쓰려면 하나씩 되돌리는 절제 실험이 필요하며 이번에는 하지 않는다
2. n=3 이라 검정력이 낮다. 양성이든 음성이든 확정 판정으로 쓰지 않는다
3. 실패해도 그대로 보고한다 — 특히 부 판정(무결손 성능 하락)이 걸리면 명시한다
4. v2 의 recon·none 수치는 **참고 기준선**으로 인용하되, v5 는 통제 비교가 아니므로
   "jepa 가 recon 을 이겼다"는 형식의 주장을 하지 않는다. 절대 성능으로 서술한다
