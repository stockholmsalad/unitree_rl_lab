## 1. 문제 — 지각의 과제는 "보는 것"이 아니다

시각 사족 보행에서 깊이 카메라는 **전방**을 보고 발은 **몸통 아래**에 닿는다.

```
시야 근거리 경계   x = 0.50 m      (전방 32.5 cm 장착 · 하향 35° · 수직 FoV 63.1°)
고관절             x = ±0.1934 m   (go2_description.urdf)
```

지형이 x = 0.50 m 를 지나 시야에서 사라진 뒤에도 발이 거기 닿기까지 시간이 남는다.

| 명령 속도 | 앞발 접지까지 | 뒷발 접지까지 |
|---|---|---|
| 0.6 m/s | 26 스텝 | 58 스텝 |
| 1.05 m/s | 15 스텝 | 33 스텝 |
| 1.5 m/s | 10 스텝 | 23 스텝 |

**발이 닿는 지형은 10~58 제어 스텝 전에 마지막으로 관측된 것이다.** 이를 **관측 사각**이라 한다.

사각은 센서 성능이 아니라 **장착 기하와 보행 기하**에서 나온다. 더 빠른 카메라는 갱신률을
높일 뿐 몸통 아래를 보지 못하고, 광각·다중 카메라는 사각을 줄이되 없애지 못하며, 배 아래를
보는 카메라는 스윙 계획 시점에 이미 늦다. TRANS 는 실기에서 시뮬레이션의 360° 와 달리
제한된 FoV 를 겪었다고 보고한다.

따라서 지각의 실제 과제는 이렇게 다시 쓰인다:

> **보이는 것을 인식하는 것이 아니라, 더 이상 보이지 않는 것을 유지하는 것.**

이 관점에서 보면 기존 방법들도 전부 같은 일을 하고 있다. 다만 유지하는 방식이 다르다.

## 2. 기존 방법의 한계 — 유지에 외부 기준이 필요하다

### (i) 기하 누적 — DreamWaQ++

외수용 센서의 낮은 갱신률(10 Hz)에 대응해 **과거 K = 5 측정을 현재 로봇 자세 기준으로
SE(3) 변환**해 결합, 시간적으로 조밀한 점군 메모리를 만든다.

**요구하는 것: 자세 변화 추정.** 관측 스트림에 없는 양이다. 그리고 TRANS 는 같은 플랫폼에서
이렇게 보고한다:

> IMU 데이터를 융합했음에도 불구하고 사족 보행 로봇의 고주파 진동이 LiDAR SLAM 알고리즘에서
> 위치 추정 드리프트를 유발하여 실제 환경에서의 내비게이션 정확도를 저하시키는 현상이 관찰되었습니다.

자세가 틀리면 기억한 지형이 틀린 좌표에 놓인다. **정책은 "틀린 지형을 확신 있게" 받는다.**

### (ii) 명시적 지형 표현 — START

로컬 지형 높이맵을 "안정적 보행을 위한 결정적 기하 특징을 전달하는 **명시적 매개체**"로 쓴다.

**요구하는 것: 시뮬레이터 GT, 그리고 형식의 사전 규정.** 높이맵은 (x, y) 하나에 높이 하나,
격자 0.1 m 다. 저자들은 결론에서 이 한계를 인정한다 — 향후 **가장자리 보존 메커니즘**과
**복셀 같은 더 표현력 있는 중간 표현**을 탐구하겠다고 밝힌다.

### (iii) 대조 정렬 — DreamWaQ++

회귀의 "실현 가능성 간극"을 피하려 대조 손실로 옮겼으나, **양성 앵커가 인코딩된 GT 높이
스캔** `g(h_t)` 다. 방식만 바뀌고 특권 의존은 남는다.

### 공통 구조

> 사라진 지형을 유지하기 위해 **관측 스트림에 없는 외부 기준**을 끌어온다.
> 하나는 **자세**(누적), 하나는 **특권 기하**(명시 표현·대조 앵커).

## 3. 본 연구의 방법 — 표현을 시간 방향으로 굴린다

기준을 밖에서 가져오는 대신 **표현 자신의 미래를 예측**해 사각을 메운다.

### 3.1 아키텍처

```
점군 K = 5 프레임  (몸통 좌표계, SE(3) 정합 없음)
        │
   PointNet-lite · masked max-pool
        │  z_e
고유감각 45 × H = 5 ──→ z_p
관측 유효도 q = [유효점 비율, 마지막 갱신 이후 경과]

  ── 표현 유지 ──
     q 신선 →  z̃ ← z_e(o)                       관측을 그대로
     q 낡음 →  z̃ ← predictor(z̃_prev, z_p)       예측으로 굴린다

정책 입력  [ z̃ , z_p , q ]  →  GRU(256)  →  MLP  →  관절 목표 12
보조손실   JEPA: predictor 가 z_e(t+k) 를 맞추도록, EMA 타깃 + VICReg
```

### 3.2 각 요소가 문제에서 어떻게 유도되는가

| 요소 | 근거 |
|---|---|
| **점군 K 프레임** | 예측에는 운동 정보가 필요하다. 정지 사진 한 장에서 미래를 짜낼 수 없다. K=5 는 DreamWaQ++ 와 같은 수 |
| **SE(3) 정합 없음** | 정합은 자세 추정을 요구한다(2절 i). 몸통 좌표계로 쌓고 인코더가 암묵적으로 처리한다 |
| **유효도 q 를 정책에 입력** | 정책이 관측 손상을 감지할 수단이 현재 없다. 실측: 부분 차폐가 완전 차폐보다 해롭다 — 완전 차폐는 일관되게 무의미해져 고유감각 보행으로 후퇴하지만 부분 차폐는 그 후퇴가 안 일어난다. q 는 실기에서 직접 얻는다(유효 픽셀 수, 타임스탬프) |
| **예측이 z_e 를 대체(연결 아님)** | 현재 구조는 `[z_e, z_p, f(z_e,z_p)]` 로, 세 번째가 앞 둘의 결정론적 함수라 **정보를 하나도 더하지 않는다.** 절제해도 성능이 안 변하는 것이 그 증거(낙폭 −0.5 pp) |
| **예측 지평 k ≈ 25** | 1 절의 사각 구간(중앙 속도 15~33 스텝)에서 계산된다. 선택이 아니라 유도 |
| **학습 중 결손 증강** | 사각은 학습에서도 겪어야 한다. 차폐 ≤ 0.5, 노후화 d ≤ 50 |

### 3.3 무엇을 해결하는가

| 기존이 요구하는 것 | 본 방법 |
|---|---|
| **자세 추정** (SE(3) 누적) | 잠재공간에서 굴리므로 정합이 없다. 진동 드리프트가 표현을 오염시키지 않는다 |
| **시뮬레이터 GT** (명시 표현·대조 앵커) | 예측 대상이 표현 자신이므로 특권 정보가 개입하지 않는다 |
| **형식의 사전 규정** (높이맵·복셀) | 무엇을 유지할지 열거하지 않는다. 예측에 유용하면 남고 아니면 사라진다 |

세 요구 모두 **관측 스트림 밖의 것**이다. 본 방법은 스트림 안의 것만 쓴다.

## 4. 검증 계획

**주 결과 — 정책이 걷는가**

- 어려운 지형(계단 9~10 cm · 틈 17~20 cm), 명령 0.6~1.5 m/s · ±0.6 rad/s
- 무결손 성공률, 그리고 사각이 넓어지는 조건(관측 정지·지연·저갱신·차폐)에서의 성공률

**절제 — 각 요소가 필요한가**

| 제거 | 예상 |
|---|---|
| 점군 이력 (K=5 → 1) | 예측 성능 저하 → 사각 구간 성능 저하 |
| 유효도 q | 부분 결손에서 후퇴 실패 (현재 관측된 실패 양식) |
| 예측 대체 → 연결 | 예측기 절제 낙폭이 0 으로 돌아감 |

**기준선** — 특권 높이맵 재구성(`recon`), 보조손실 없음(`none`). 통제 비교가 아니라 맥락으로 인용한다.

## 5. 이 논증의 한계

- 사각 계산은 **평지 등속 전진**을 가정한다. 회전·가감속·경사에서 달라진다
- 예측이 기하 누적보다 나은지는 **직접 비교하지 않는다.** 주장은 "요구 조건이 다르다"이며,
  자세 오차 하에서의 비교는 향후 과제다
- 실험 지형은 높이장이므로 2 절 (ii) 의 형식 한계(돌출부·물성)가 드러나는 조건이 아니다
- 부수적으로, JEPA 손실은 관측 스트림만으로 계산되므로 배포 후 표현 갱신에도 쓸 수 있으나
  본 연구에서 직접 검증하지 않는다
