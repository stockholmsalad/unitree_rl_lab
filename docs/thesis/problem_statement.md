# 문제 정의 — 관측 사각(observation blind interval)

*1·2장의 척추. 수치는 전부 저장소의 설정 파일과 URDF 에서 나온 것이며 추정치가 아니다.*

## 1. 발이 닿는 지형은 그 순간 보이지 않는다

깊이 카메라는 **전방**을 본다. 발은 **몸통 아래**에 닿는다. 이 둘의 간격이 문제의 출발점이다.

**카메라 기하** (`env_cfg.py`, `pc_scanner`)

```
장착      전방 0.325 m · 상방 0.045 m · 하향 35°
시야      수평 78.7° · 수직 63.1° · 유효 거리 2.0 m
지면 관측 x ∈ [0.50, 2.32] m      ← 근거리 경계가 0.50 m
```

**발 위치** (`go2_description.urdf`)

```
고관절    x = ±0.1934 m       앞발 ≈ +0.19 · 뒷발 ≈ −0.19
```

지형은 로봇이 전진하면서 x 좌표가 줄어든다. **x = 0.50 m 를 지나면 시야에서 사라지지만,
발이 거기 닿기까지는 아직 시간이 남아 있다.**

| 명령 속도 | 앞발 접지까지 | 뒷발 접지까지 |
|---|---|---|
| 0.6 m/s (하한) | 0.52 s = **26 스텝** | 1.15 s = **58 스텝** |
| 1.05 m/s (중앙) | 0.30 s = **15 스텝** | 0.66 s = **33 스텝** |
| 1.5 m/s (상한) | 0.21 s = **10 스텝** | 0.46 s = **23 스텝** |

> **정책은 최소 10~58 제어 스텝 전에 관측된 지형 위에 발을 딛는다.**

이 구간을 **관측 사각**이라 부른다. 접지 시점에 그 지형에 대한 새 정보는 존재하지 않는다.

## 2. 이것은 센서 성능 문제가 아니다

"더 좋은 센서를 쓰면 되지 않나"에 대한 답을 미리 적는다. 네 가지 모두 사각을 없애지 못한다.

**(a) 더 빠른 카메라 (10 Hz → 90 Hz)**
사각은 **갱신률**이 아니라 **위치**에서 생긴다. 초당 90 장을 찍어도 몸통 아래 지형은 찍히지
않는다. 갱신률은 사각 밖 지형의 신선도를 높일 뿐이다.

**(b) 광각 렌즈 · 다중 카메라**
시야를 넓히면 근거리 경계를 0.50 m 에서 다소 당길 수 있다. 그러나 몸통과 다리가 물리적으로
가리는 영역은 남고, 경계를 0 으로 만들 수는 없다. 사각이 줄어들 뿐 사라지지 않는다.

**(c) 배 아래를 보는 하향 카메라**
접지 순간의 지면은 볼 수 있으나 **이미 늦다.** 발 놓을 자리는 스윙이 시작되기 전에 정해져야
하고, 그 시점에 목표 지점은 아직 전방에 있다. 그리고 스윙 중인 다리가 시야를 가린다.

**(d) 360° LiDAR**
수평 시야는 해결되지만 자기 몸통 아래는 여전히 보이지 않는다. TRANS 는 실기에서 시뮬레이션의
360° 와 달리 **제한된 FoV** 를 겪었고, 시야 밖은 가정으로 처리했다고 밝힌다.

**사각은 장착 기하와 보행 기하에서 나오는 필연이다.** 하드웨어로 완화할 수는 있어도
제거할 수 없다.

## 3. 사각이 실제로 무엇을 부수는가

사각 자체보다 **정책이 사각을 어떻게 다루는가**가 문제다. 본 연구의 측정은 현재의 정책들이
사각을 잘못 다루고 있음을 보인다.

**낡은 관측이 무관측보다 해롭다** (어려운 지형, 15 런 평균, 무결손 92.80 %)

```
freeze  관측 정지     57.23 %   −35.56 pp
blind   지형 정보 0   66.91 %   −25.89 pp      ← freeze 가 9.7 pp 더 나쁘다
```

지형 정보를 **통째로 지운 것보다 낡은 정보를 계속 넣어 주는 편이 더 해롭다.**

**부분 차폐가 완전 차폐보다 해롭다** (v2, 어려운 지형)

```
recon s2   레벨 0.8 에서 31.34 %  →  레벨 1.0 에서 57.75 %   (반등)
none  s5   레벨 0.8 에서  1.84 %  →  레벨 1.0 에서 26.21 %   (반등)
```

완전 차폐에서는 입력이 일관되게 무의미해져 정책이 고유감각 보행으로 후퇴한다. 부분 차폐에서는
그 후퇴가 일어나지 않고 잘못된 지형을 믿는다.

**두 관측이 같은 것을 말한다** — 시간축과 공간축에서 독립적으로:

> 정책은 **불완전한 정보를 완전한 것으로 취급한다.** 그것이 없는 것보다 나쁘다.

## 4. 기존 방법은 사각을 어떻게 메우나 — 그리고 그 대가

### (i) 기하 정합 누적 — DreamWaQ++

외수용 센서의 낮은 갱신률(10 Hz)에 대응해 **과거 K=5 측정을 현재 로봇 자세 기준으로
SE(3) 변환**해 결합하고, 시간적으로 조밀한 점군 메모리를 만든다.

**대가 — 주행거리계 의존.** SE(3) 변환에는 자세 변화 추정이 필요하다. 그리고 TRANS 는 같은
플랫폼에서 이렇게 보고한다:

> IMU 데이터를 융합했음에도 불구하고 **사족 보행 로봇의 고주파 진동이 LiDAR SLAM 알고리즘에서
> 위치 추정 드리프트를 유발**하여 실제 환경에서의 내비게이션 정확도를 저하시키는 현상이
> 관찰되었습니다.

정합이 틀어지면 기억한 지형이 엉뚱한 좌표에 놓인다. **낡은 관측이 무관측보다 해롭다는 3절의
관측을 감안하면, 잘못 정합된 기억은 기억이 없는 것보다 나쁠 수 있다.**

**두 번째 대가 — 본 것만 채워진다.** 누적 메모리는 과거에 관측된 것의 합집합이다. 한 번도
시야에 들어오지 않은 영역, 그리고 관측 이후 변한 지형(무너진 자갈, 밟혀 눌린 풀)은 채워지지
않는다.

### (ii) 명시적 지형 표현 — START

로컬 지형 높이맵을 "안정적 보행을 위한 결정적 기하 특징을 전달하는 **명시적 매개체**"로 쓴다.
저자들은 결론에서 이 표현의 한계를 인정한다 — 향후 **가장자리 보존 메커니즘**을 도입하고
**복셀 같은 더 표현력 있는 중간 표현**을 탐구하겠다고 밝힌다.

**대가 — 무엇을 담을지를 사람이 정한다.** 높이맵은 (x, y) 하나에 높이 하나, 격자 0.1 m 다.
따라서 돌출부, 0.1 m 미만 구조(계단 가장자리), 높이가 아닌 물성(젖음·마찰·연성)은 원리적으로
담기지 않는다. 형식을 복셀로 바꾸면 돌출부는 해결되지만 물성은 여전히 담기지 않는다.

### (iii) 공통점 — 표현이 특권 정보에 고정된다

| | 표현을 무엇에 고정하는가 |
|---|---|
| START | 높이맵을 정책에 직접 공급 |
| DreamWaQ++ | 대조 손실의 **양성 앵커 = GT 높이 스캔** `g(h_t)` |
| 본 연구의 `recon` 조건 | `z_e` → GT 높이맵 회귀 |

DreamWaQ++ 는 회귀의 "실현 가능성 간극"을 피하려고 회귀에서 대조로 옮겼으나, **앵커는 여전히
시뮬레이터에서만 얻는 GT 높이 스캔**이다. 방식이 바뀌었을 뿐 표현이 사람이 규정한 특권 표현에
끌려가는 구조는 같다.

## 5. 본 연구의 접근

> **사각을 기억으로 메우는 대신, 표현을 시간 방향으로 굴려서 메운다.**

관측 시점의 잠재 표현 `z_e(t)` 로부터 `z_e(t+k)` 를 예측하도록 학습한다. 사각 구간 동안
정책은 마지막 관측을 그대로 쓰는 대신 **그 관측을 굴린 추정치**를 쓴다.

**(i) 주행거리계가 필요 없다.** SE(3) 변환이 없으므로 자세 추정 오차가 개입하지 않는다.
진동에 의한 드리프트가 표현을 오염시키지 않는다.

**(ii) 특권 타깃이 필요 없다.** 예측 대상이 표현 자신이므로 시뮬레이터 GT 가 개입하지 않는다.
무엇을 담을지 사람이 열거하지 않는다 — 예측에 유용한 것이면 남고 아니면 사라진다.

**(iii) 본 적 없는 것도 다룰 여지가 있다.** 누적은 관측의 합집합이지만 예측은 외삽이다.
다만 본 연구는 이 이점을 실험으로 보이지 못했다(7절).

## 6. 필요한 예측 지평은 선택이 아니라 계산된다

1 절의 표가 그대로 지평의 요구 조건이다.

```
사각 구간   10 ~ 58 스텝 (속도·앞뒤발에 따라)
중앙값 부근 15 ~ 33 스텝
```

**k = 25 는 이 범위의 한가운데다.** 본 연구가 처음에 쓴 k = 100 은 사각 구간의 3~7 배로,
정책이 필요로 하지 않는 미래를 예측하고 있었다. 사전학습 지평 스윕에서 k=100 의 copy 대비
skill 이 가장 높았던 것(0.584)은 **예측 과제로서 쉬웠다는 뜻이지 정책에 유용하다는 뜻이 아니다** —
지평이 길수록 "직전 프레임 복사"가 나쁜 기준선이 되어 이기기 쉬워진다.

## 7. 이 문제 정의의 사정거리

- 사각 구간 계산은 **평지 등속 전진**을 가정한다. 회전·가감속·지형 경사에서는 달라진다
- 발 위치를 고관절 x 좌표(±0.1934 m)로 근사했다. 실제 접지점은 보행 주기에 따라 전후로 흔들린다
- 예측이 누적보다 나은지는 본 연구가 직접 비교하지 않았다. 두 접근의 **요구 조건**(주행거리계,
  특권 타깃)이 다르다는 것이 본 연구의 주장이며, 성능 우위는 별도 문제다
- 실험 지형은 높이장이므로 4절 (ii) 의 형식 한계(돌출부·물성)가 드러나는 조건이 아니다
